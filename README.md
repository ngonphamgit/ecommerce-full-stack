Full Stack E-Commerce Web Application

A full stack web application built with HTML, CSS, 
and Javascript for the frontend, Java and Spring Boot
for the backend, and PostgreSQL for the database. Users
can search and favorite products, manage shopping cart,
view user profile, and see past orders


====== FEATURES ======
- Product search
- Favorites
- User registration and login
- JWT authentication
- Shopping cart
- User profile
- Order history


====== TECH STACK ======
=== Frontend
- HTML
- CSS
- Javascript

=== Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA

=== Database
- PostgreSQL
